# Support

Use the right channel for the kind of help you need.

## Questions and Usage Help

Use GitHub Discussions for:

- Setup and configuration questions
- Store-selection or deployment guidance
- API usage questions
- Design discussion before large changes

Discussion board:

- <https://github.com/jcputney/ratchet/discussions>

Documentation site:

- <https://ratchet.jcputney.dev>

## Bug Reports

Use GitHub Issues for:

- Reproducible defects
- Regressions
- Documentation errors with a concrete fix
- Focused feature requests

Issue tracker:

- <https://github.com/jcputney/ratchet/issues>

When opening an issue, include:

- Ratchet version or commit SHA
- Java version
- Jakarta EE runtime
- Store backend
- Relevant logs and stack traces
- A minimal reproduction if possible

## Security Reports

For undisclosed vulnerabilities, follow [SECURITY.md](./SECURITY.md). Do not open a public issue first.
